# SkillHub

Automatically discover, collect, deduplicate, and share skills across supported AI agents through one local library. Manage your skills with optional cross-device synchronization, automated self-tests, and a compact visual directory.

## Install

Copy the following prompt into your AI agent:

```text
Install and initialize SkillHub from https://github.com/zhaoqingxia06/SkillHub. Follow skill-manager/SKILL.md and run the built-in self-test.
```
